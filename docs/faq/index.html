VaneTools — frequently asked questions

Short answers about the VaneTools directory and its MCP endpoint at https://vanetools.com/mcp: what it covers, pricing, auth, data source, refresh cadence and licensing. Longer setup instructions live in the connection guide.

The directory

What is VaneTools?

A bilingual (English/中文) AI directory that curates 38,182 resources across seven types — AI apps, prompts, agent skills, plugins, workflows, MCP servers and learning resources. Every listing is editorially reviewed and links to a bilingual detail page on vanetools.com with the project's official website.

How is the catalog maintained?

Submissions plus editorial curation. New resources go through review on the main site before they enter the catalog; the open index in this repo's catalog.json is regenerated deterministically from the public feed so the data stays auditable.

The MCP endpoint

Is the endpoint free to use?

Yes. Public and read-only, no API key, no account, no charge. Add the URL to any MCP client and query away.

Do I need to install anything?

No. It is a remote HTTP MCP server — no npm package, no Python env, no updates to manage. The config in the connection guide is the entire setup.

Does it work in Chinese?

The catalog is bilingual. Every resource has a Chinese detail page under vanetools.com/zh, and queries in either language hit the same index.

Data

Where does the data come from?

The VaneTools editorial pipeline — submissions plus curation across seven resource types. The same data is published as llms.txt / llms-full.txt and mirrored as structured JSON in this repo’s tools/catalog.json.

How many resources does the catalog cover?

38,182 as of October 2026: 22,733 AI apps, 6,170 prompts, 4,893 skills, 3,082 plugins, 989 workflows, 278 MCP servers, 37 learning resources. The catalog page has the type-by-type breakdown.

How often is the data refreshed?

The live endpoint queries the current catalog, which is updated continuously. The JSON snapshot in this repo is regenerated alongside the public llms.txt feed.

Licensing & ecosystem

Can I reuse the catalog data?

Yes — catalog.json is MIT licensed. It contains public metadata only (name, type, detail-page URL, official website); descriptions stay on the vanetools.com detail pages. Attribution is appreciated but not required.

Is this server in the official MCP Registry?

Yes — namespace com.vanetools/vanetools-directory. Registry-syncing aggregators such as Glama and PulseMCP list it automatically. It is also published on Smithery and indexed by mcpservers.org and Cursor Directory.
