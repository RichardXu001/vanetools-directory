The catalog: 38,182 AI resources, open and machine-readable

VaneTools curates 38,182 AI resources across seven types. This page breaks the catalog down by type and links the full machine-readable index (tools/catalog.json, MIT licensed). Every entry in the catalog links to a bilingual detail page on vanetools.com; the descriptions intentionally live there, not in this repo, so the two never drift apart.

Download the index

tools/catalog.json is a single JSON file with one record per resource:

{
  "total": 38182,
  "fields": ["name", "type", "url", "website"],
  "resources": [
    ["007Hub", "plugin", "https://vanetools.com/plugins/007hub", "https://chromewebstore.google.com/…"],
    ["008", "app", "https://vanetools.com/tools/008", "https://008agent.ai"],
    …
  ]
}

Regenerate it any time with node scripts/refresh-catalog.mjs — it reads the public llms-full.txt feed and writes deterministic output, so diffs in review are exactly the catalog changes.

Prefer querying over downloading?

Connect the VaneTools MCP endpoint to Claude, Cursor or VS Code and let your agent query the live catalog in natural language — no file to keep in sync. The connection guide has copy-paste configs for all three clients.

How the catalog is maintained

Listings are curated and deduplicated by the VaneTools editors; new submissions go through the main site. The catalog grew from ~30k to 38k resources over the past quarter and is refreshed continuously — this repo’s snapshot is regenerated alongside the public llms.txt feed.
