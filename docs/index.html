VaneTools MCP Server: search 38,182 curated AI resources from any MCP client

The VaneTools MCP server exposes a curated directory of 38,182 AI resources — 22,733 AI apps, 6,170 prompts, 4,893 skills, 3,082 plugins, 989 workflows, 278 MCP servers and 37 learning resources — to any MCP-compatible client. The endpoint at https://vanetools.com/mcp is public and read-only: no API key, no sign-up, no rate-limit gymnastics.

VaneTools is a bilingual (English/Chinese) AI directory. This site documents its MCP endpoint and the open catalog data behind it. The full catalog index lives in the GitHub repository (tools/catalog.json, MIT licensed), and every listing links back to a detail page on vanetools.com.

Connect in 30 seconds

Paste this into your MCP client configuration and restart the client:

{
  "mcpServers": {
    "vanetools": {
      "url": "https://vanetools.com/mcp"
    }
  }
}

Works in Claude Desktop (Settings → Developer → Edit Config), Cursor (Settings → MCP), and VS Code (as an HTTP server entry in mcp.json). Step-by-step instructions for each client are on the connection guide.

What can an agent search for?

The endpoint answers natural-language queries like “find MCP servers for Postgres” or “recommend open-source tools for AI image upscaling” against the curated catalog. Results come back with names, detail-page links and official websites, so an agent can cite sources instead of hallucinating tool names.

Why a remote endpoint instead of a local package?

A remote (HTTP) MCP server needs no install, no Node/Python runtime and no updates: the config above is the whole setup, and improvements to search quality land for every client at once. It also means the agent always queries the live catalog — 38k resources and counting — instead of a snapshot baked into an npm package.
