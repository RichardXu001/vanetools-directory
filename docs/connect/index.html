How to connect a remote MCP server to Claude Desktop, Cursor and VS Code

By VaneTools Team · Published 2026-10-15 · 2-minute setup

A remote (HTTP) MCP server needs no install, no runtime and no build step — you only add its URL to your client’s config. Below are the exact copy-paste configs for the three most common MCP clients, using the free public VaneTools endpoint (https://vanetools.com/mcp) as the working example. The same pattern works for any remote MCP server: swap the URL.

The one config to know

Most clients read an mcpServers block. For a remote server you specify just a name and a URL:

{
  "mcpServers": {
    "vanetools": {
      "url": "https://vanetools.com/mcp"
    }
  }
}

The VaneTools endpoint is read-only and unauthenticated, so there is nothing else to configure — no env, no headers, no tokens.

Claude Desktop

  1. Open Settings → Developer → Edit Config. This opens claude_desktop_config.json.
  2. Paste the JSON block above into the file (merge it if you already have other servers).
  3. Save and fully restart Claude Desktop (not just the window).
  4. Open a chat, click the tools icon — you should see the vanetools tools listed.

The same JSON lives in examples/claude-desktop.json in the repo.

Cursor

  1. Open Settings → MCP → Add new global MCP server.
  2. Paste the same mcpServers JSON and save.
  3. The entry appears in your MCP list; a green dot means connected.

Cursor-specific notes: the JSON is identical to Claude Desktop’s. Project-level config also works (.cursor/mcp.json in the repo root) if you want the server available only in one project.

VS Code

  1. Command Palette → MCP: Add Server (or edit mcp.json directly).
  2. VS Code uses a slightly different shape — the server type is http:
{
  "servers": {
    "vanetools": {
      "type": "http",
      "url": "https://vanetools.com/mcp"
    }
  }
}
  1. Reload the window. The server shows under the MCP section of the Chat view.

Troubleshooting

SymptomFix
Server shows but no tools listedRemote servers register tools dynamically — ask the agent to “list your tools” or restart the client.
Connection refused / timeoutCheck corporate proxies; the endpoint is plain HTTPS on vanetools.com. Test with curl -I https://vanetools.com/mcp.
Config edits ignoredClaude Desktop and Cursor read config at startup — a full restart (not just a new chat) is required.

What to try once connected

Ask your agent things like “use vanetools to find MCP servers for working with Postgres” or “search the vanetools catalog for open-source AI image upscalers”. Every result links to a detail page on vanetools.com with the full description and the project’s official site, so citations stay verifiable. The MCP-servers category alone indexes 278 curated servers.
